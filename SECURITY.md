# Security policy

Do not post credentials, account identifiers, vulnerability details, real .pkn exports, cloud preference snapshots or personal screenshots in public issues.

When private vulnerability reporting is enabled on the public repository, use the Security tab to submit a private report. Until that channel is available, do not disclose sensitive details publicly.

Include the affected version, synthetic reproduction, impact and suggested remediation. The beta installer is unsigned; compare its SHA-256 against the checksum published with the release.

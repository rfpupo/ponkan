# Contributing to Ponkan

Thank you for helping improve Ponkan, an independent, free VALORANT settings profile manager. English is the primary repository language; Portuguese and Spanish UI translations are welcome.

- Discuss substantial behavior or visual changes before implementing them. Preserve the minimal UI and avoid unrelated features.
- Work in the isolated Dev configuration. Never use a production Riot account or personal profile data in automated tests.
- Keep changes small; provide reproduction steps, tests and screenshots with synthetic data when applicable.
- Build from source on Windows using the instructions in README. Report changes and reproduction steps with synthetic data.
- Disclose material AI assistance and review generated code for correctness, licensing, privacy and security. Contributors must have rights to submit their contributions under the project's selected license.
- Never include credentials, access tokens, private settings, personal profile exports or signing keys in issues, logs or commits.

Code and contributions will be governed by the final approved project license. This document is a local draft until the maintainer authorizes publication.
